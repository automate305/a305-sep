● Automate305 SEP

Sales engagement API is running. This service has no web UI — it exposes JSON endpoints only.

Endpoints (require the x-a305-secret header):

  • POST /api/send — process today's send queue
  • POST /api/enroll — add contacts to a sequence
  • POST /api/update-status — mark replied / bounced / unsubscribed
  • POST /api/generate-sequence — AI sequence generation
  • POST /api/approve-sequence — DRAFT → APPROVED → ACTIVE lifecycle
  • POST /api/ingest-replies — IMAP reply ingestion
  • POST /api/compute-scores — recalculate mailbox health scores
  • GET /api/dns-check — SPF/DKIM/DMARC/blacklist check
  • GET /api/hold-queue — view held messages
  • POST /api/hold-queue — approve or skip held items
  • POST /api/kill-switch — toggle global kill switch
  • GET /api/dashboard — full dashboard data (brand-scoped)

Health & config check (no auth): /api/health

Operator dashboard: /dashboard.html (key required)
