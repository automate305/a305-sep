● Automate305 SEP

Sales engagement API is running. This service has no web UI — it exposes JSON endpoints only.

Endpoints (all POST, require the x-a305-secret header):

  • /api/send — process today's queue
  • /api/enroll — add contacts to a sequence
  • /api/update-status — mark replied / bounced / unsubscribed

Health & config check (no auth): /api/health

Operator dashboard: /dashboard.html (key required)
